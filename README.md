# Campus Eye Frontend

Frontend interface for the Campus Eye campus security monitoring platform.

## Technology

- React
- Vite
- React Router
- Recharts
- Lucide React

## Main Features

- Dashboard
- Live camera monitoring
- Security alerts
- Evidence review
- People and ReID tracks
- System health monitoring
- Authentication
